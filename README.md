One fortune-cookie line written for an AI agent, and nothing else: a small
deterministic Node program that gates its own text (1–140 characters, UTF-8, one
line, not only white space) and writes it to `/output/entry.txt` for the house
judge to read byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
